# Vishal-Mega-Mart-Dashboard-V2

📦 Tab 1: Inventory
LiveStock — Physical inventory levels in stores (SAP vs RFID)
CycleCount — How well stores are auditing their own inventory
Both sections answer the same question: "Where is our stock and is it accurate?"

🧾 Tab 2: Sales & Returns
Sale Dashboard — What got sold (DPOS + RFID checkouts)
Void Dashboard — What got voided at billing
Return Dashboard — What came back from customers
These three all revolve around customer-side transactions — items leaving and coming back through the billing counter.

🏭 Tab 3: Warehouse & DC
Vendor Discrepancy — What vendors shipped vs what we actually received
DC Validation — How many HUs got validated at the distribution center
DC Encoding — Hourly encoding activity at the warehouse
These are all supply-chain/backend operations — before stock even reaches a store.

🏷️ Tab 4: Tag Management
Tag Location — Where tags are physically located (Store vs Warehouse)
Tag Cycle Count — How many times tags have been scanned/recycled
Both sections are specifically about RFID tags as physical objects, separate from the inventory they represent.

🏪 Tab 5: Store Operations
Store Validation — HU validation done at the store level (store receiving, not DC)
